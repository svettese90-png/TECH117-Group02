Introduction

This project uses an Arduino Uno, a stepper motor, an infrared sensor, an LCD screen, and a potentiometer to operate a pet feeder. It aligns with the WHO's Sustainability Development Goals in the area of Reducing Inequalities and Responsible Consumption and Production.

The goal of the project is to create a system that can dispense food at regular intervals using delay. A stepper motor will operate an augur that turns a certain number of timesat predetermined intervals. The size of the portions (i.e. the number of times the augur turns) is controlled by a potentiometer. An infrared sensor will detect when the amount of food in the dispenser is low and display this on an LCD screen.

This addresses inequality by easing the cognitive load for neurodivergent pet owners, and responsible consumption by ensuring the pet in question has a consistent food supply while minimizing waste.

Potential roadblocks include the time taken to print the augur, the number of ports available on the Arduino, and the complexity of integrating all components.

Circuit Diagram

A stepper motor turns an augur at predetermined intervals to dispense food into a bowl. An infrared sensor detects when the level of food in the dispenser is low, and the LCD screen displays the status. A potentiometer can be used to adjust portion size by determining the number of rotations of the augur.

Environmental Impact Assessment

  • Materials: The Arduino Uno is RoHS and WEEE compliant, limiting hazardous substances. The augur is 3D printed using PLA, a biodegradable material.
  • Energy Efficiency: The circuit draws minimal power (~50 mA at 5V), ideal for USB or solar power.
  • Reusability: All components are modular and reusable, reducing electronic waste.
  • Packaging & Shipping: Ordering all components from a single supplier helps minimize carbon footprint.

Arduino Code

The following Arduino code controls the system, lighting LEDs and activating the buzzer based on distance readings from the HC-SR04 sensor.

 
  
// Collision Warning System with Distance Sensor (HC-SR04)
// Author: Ana Rodrigues
// Oct 2, 2025
// Object is farther than 50cm: Green LED lights up
// Object is closer than 50 cm, but more than 10cm away: Yellow LED lights, buzzer plays 300Hz tone
// Object is closer than 10cm: Red LED lights up, buzzer plays 500Hz tone

//LED pins
const int greenLED = 2;
const int yellowLED = 3;
const int redLED = 4;

// Ultrasonic sensor pins
const int trigPin = 9;
const int echoPin = 10;

// Passive buzzer pin
const int buzzer = 11;

void setup() {
  pinMode(greenLED, OUTPUT);
  pinMode(yellowLED, OUTPUT);
  pinMode(redLED, OUTPUT);
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  Serial.begin(9600);
}

void loop() {
  // Measure distance
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  long duration = pulseIn(echoPin, HIGH);
  long distance = duration * 0.034 / 2;

  Serial.print("Distance: ");
  Serial.print(distance);
  Serial.println(" cm");
  
  //Error in measurement:
  if (distance <= 0)
    return;

  //Too close:
  if (distance <= 10) {
    digitalWrite(greenLED, LOW);
    digitalWrite(yellowLED, LOW);
    digitalWrite(redLED, HIGH);
    tone(buzzer, 500); // Play 500Hz tone
    return;
  }

  //Midrange:
  if (distance <= 30) {
    digitalWrite(greenLED, LOW);
    digitalWrite(yellowLED, HIGH);
    digitalWrite(redLED, LOW);
    tone(buzzer, 300); // Play 300Hz tone
    return;
  }

  //Normal status:
  digitalWrite(greenLED, HIGH);
  digitalWrite(yellowLED, LOW);
  digitalWrite(redLED, LOW);
  noTone(buzzer); // stop buzzer

  delay(100);
}

Conclusion

The system effectively alerts users to the level of food present in the bird feeder.
